# DevOps Review Checklist

A DevOps change is review-ready when:

- [ ] The scope is clear.
- [ ] Affected files or resources are listed.
- [ ] Local vs Docker paths are clear.
- [ ] Port bindings are reviewed.
- [ ] Secrets are not hardcoded.
- [ ] Environment variables are documented.
- [ ] Validation commands are listed.
- [ ] Rollback steps are listed.
- [ ] Observability/logging impact is considered.
- [ ] Handoff is clear.
